# paper-system

基于 MinerU 的学术论文阅读 / 双语翻译 / 证据问答 / 科研导读系统。

## 快速开始

1. **访问**: `http://<服务器IP>:7861`（初始管理员 `admin`，密码见 `.env` 的 ADMIN_INITIAL_PASSWORD）
2. **配 key**: 登录 → 设置页 → 填自己的 GLM/OpenAI 兼容 API（聊天+翻译各一路，可测试连接）
3. **建账号**: 管理员在「管理」页生成邀请码 → 其他人凭邀请码注册 → 各自配 key
4. **用起来**: 拖 PDF 上传 → 解析完成自动建索引 → 点开阅读（双栏：左 PDF / 右原文|双语|中文）→ 💬问答 / 导读

## 功能地图

| 页面 | 功能 |
|---|---|
| 阅读双栏 | pdf.js 原 PDF ‖ 原文/双语对照/中文/JSON 四视图；点段落跳页+bbox 高亮 |
| 问答 | 单篇全文直读、多篇对比（≤10篇自动检索取证）、引用[n]点击跳 PDF 页 |
| 导读 | 9 字段科研模板（问题/核心思想/方法/数据集/基线/指标/消融/复杂度/局限），带页码证据 |
| 任务中心 | 解析/翻译进度（段级）、重试/取消、批量暂停恢复、token 用量（按用户） |
| 管理页 | 邀请码、按用户限额微调、公共额度池开关（默认关） |
| 设置 | BYOK 配置（加密存储）、测试连接 |
| 回收站 | 软删除 30 天可恢复 |

## 调度规则（GPU 共享）

- 手动上传的任务**插队**（interactive），批量导入排后台（background），层内按用户轮转——单人批量不阻塞他人
- 解析 GPU 串行；翻译每用户并发 2；embedding 回填后台批处理
- member 限额：100MB/500页/200篇每天（admin 全豁免，管理页可按人调整）

## 技术栈

FastAPI + SQLite(FTS5+向量) + numpy ｜ MinerU 4.1.6 (vLLM, GPU) ｜ Ollama BGE-M3 (GPU) ｜ Caddy ｜ 原生 JS + pdf.js

详见 `DEPLOY.md`（部署/迁移/备份）与 `config.example.yaml`（调优项）。
